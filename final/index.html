At a glance

Neural networks are computing systems inspired by the biological neural networks found in animal brains. They learn patterns from data by adjusting internal parameters called weights and biases. Typical building blocks are layers of interconnected nodes ("neurons") that transform inputs into outputs using mathematical functions.

Input Layer
Receives raw data
Hidden Layers
Process features
Output Layer
Prediction/result
Activation
Non-linear transform

Common uses

  • Computer vision (image recognition)
  • Natural language processing (translation, chatbots)
  • Speech recognition and synthesis
  • Recommendation systems
